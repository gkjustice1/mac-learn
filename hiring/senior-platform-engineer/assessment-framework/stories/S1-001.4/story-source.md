# Assessment Source — S1-001.4 Repository REST/GraphQL API & CI Recovery

## Source story

Implement the Repository REST/GraphQL API on top of the existing Repository domain, PostgreSQL persistence adapter, and application service. The story is complete only when build, migrations, unit tests, contract tests, PostgreSQL integration tests, and CI all pass and the pull request is review-ready.

## Candidate assessment objective

Evaluate whether a senior engineer can inherit an active feature branch, understand the existing architecture, diagnose evidence-backed failures, make minimal correct changes, and drive the story through Definition of Done.

## Competencies measured

- TypeScript and Node.js engineering
- REST API design and error mapping
- GraphQL schema/resolver implementation
- PostgreSQL migrations and transactional integration
- Unit, contract, and integration testing
- Git and pull-request discipline
- GitHub Actions configuration and debugging
- Root-cause analysis
- Definition of Done judgment
- Written technical communication

## Sanitization rules

The assessment must not contain production credentials, customer/student data, proprietary Master Blueprint content, production infrastructure identifiers, or internal secrets. All tenants, users, repository names, and content are synthetic.

## Scope intentionally excluded

- Production deployment credentials
- Live MAC Enterprise content
- Real identity-provider configuration
- Real commercial/customer data
- Sprint work beyond S1-001.4
