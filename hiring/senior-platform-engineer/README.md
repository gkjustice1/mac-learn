# MEKOS Senior Full-Stack Platform Engineer Hiring Package

This directory is the authoritative hiring operating system for the MEKOS Senior Full-Stack Platform Engineer role.

## Candidate-facing assets

- `01-job-posting.md` — canonical posting for LinkedIn, Indeed, Upwork, recruiters, and direct outreach.
- `02-candidate-application.md` — structured application form.
- `assessment/README.md` — candidate coding exercise and submission instructions.

## Internal hiring assets

- `03-recruiter-scorecard.md` — recruiter screen and pass/fail criteria.
- `04-technical-interview-scorecard.md` — technical interview questions, expected signals, and 100-point scoring model.
- `05-hiring-process.md` — interview stages, decision gates, ownership, and SLA targets.
- `06-30-60-90-day-plan.md` — onboarding and success plan.

## Operating rule

No candidate advances because of resume prestige alone. Advancement requires evidence against the defined gate for the current stage. Final hiring decisions require documented scores, assessment evidence, and explicit risk notes.
